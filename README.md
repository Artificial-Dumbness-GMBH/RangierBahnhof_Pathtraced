# Rangierbahnhof

## In VS Code starten

1. Auf GitHub **Code → Download ZIP** wählen und die heruntergeladene ZIP entpacken.
2. Den entpackten Repository-Ordner in VS Code über **Datei → Ordner öffnen** öffnen.
3. Ein **JDK ab Version 17** und das **Extension Pack for Java** in VS Code installieren, falls sie fehlen. Warten, bis VS Code das Maven-Projekt im Ordner `rangierbahnhof/` erkannt hat.
4. **F5** drücken und bei Bedarf **Rangierbahnhof starten** auswählen. Alternativ in `rangierbahnhof/src/main/java/rangierbahnhof/Main.java` auf **Run** klicken.

Die 3D-Ansicht öffnet sich im Browser. Falls sie sich nicht automatisch öffnet, steht die Adresse im VS-Code-Terminal (normalerweise `http://127.0.0.1:8765/`).
